# Notes

Daily lock-in notes (`day-NN.md`) and weekly exit quizzes (`weekN-quiz.md`).

## Daily note template

```
## Day NN — <topic>
Designed: <link to design note>
Built: <bullets>
Broke: predicted <X>, observed <Y>, learned <Z>
Quiz misses: <terms to drill>
One paragraph I could say in an interview: <write it>
```

The "Broke" line is the one that matters. A prediction that matched reality
taught you nothing; the gap is the lesson.

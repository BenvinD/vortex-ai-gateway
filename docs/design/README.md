# Design notes

Written **before** any code is generated, one file per working day:
`day-NN.md`, 5–10 lines.

Each note answers three questions:

1. What am I building?
2. What are the 2–3 alternatives?
3. Which did I choose, and why?

The point is that the design exists outside the code, in your own words, before
the implementation makes the decision feel inevitable.
